Key Findings
5 Takeaways from the Comparison
1
Random Forest dominates overall — 87.43% accuracy, +2.02pp over k-NN. Non-linear decision boundaries from 200 trees decisively beat linear classifiers.
2
HOG helps linear models, hurts non-linear ones — LogReg/SVM gain +0.23–0.43% with HOG while reducing params by 58.6%. RF/k-NN lose 3.08pp / 1.57pp — the fixed vocabulary discards pixel detail they need.
3
k-NN memory/latency trade-off — Switching to HOG reduces memory by 58.7% (179.4→74.2 MiB) and latency by 2.4× (0.274→0.098 ms/img) at only 1.57pp accuracy cost.
4
Linear classifiers are fastest — LogReg on HOG is 685× faster than k-NN on pixels. Essential for real-time inventory tagging at scale.
5
Shirt (class 6) is universally the hardest — Mean recall across all 8 configs is only 57.7%. No model exceeds 62.6%. This is a representation problem, not a hyperparameter problem.
For production deployment
If accuracy matters most: Random Forest on pixels (87.43%). If speed and size matter: Logistic Regression on HOG — 84.55% accuracy at 0.0004 ms/img with only 3,250 parameters.

Error Analysis
The Shirt Dilemma
Why fixed descriptors fail for fine-grained upper-body classification
Confusion Pattern

Shirt (class 6) is confused with upper-body garments sharing similar 28×28 silhouettes:

Shirt → T-shirt/top ~15–16% of Shirts
Shirt → Pullover ~12–14% of Shirts
Pullover → Coat ~8–10% of Pullovers
At 28×28 px, collar shapes, button rows, plackets, and knit textures become near-indistinguishable blobs under fixed feature extraction.
Why Pixels Fail

784 independent positions — no notion that a collar shifted slightly up is the same cue. Small translations alter many coordinates while the garment label is unchanged.

Why HOG Fails

Captures global edge orientations (good for distinct silhouettes). Cannot learn that button-row edges near the neckline are more diagnostic. Cell pooling removes exactly the fine spatial cues needed.

Why Linear Boundaries Fail

A hyperplane cannot create discriminative evidence absent in the input. If Shirt and T-shirt overlap in pixel/HOG space, changing the margin penalty C cannot resolve it.

Phase 2 Preview
Why a CNN is the Logical Next Step
Phase 1 identifies the gap; Phase 2 closes it
The Identified Gap
57.7% mean Shirt recall — across all 8 configurations
This is a representation failure, not a hyperparameter failure. No amount of tuning fixed/handcrafted features can resolve overlapping garment silhouettes at 28×28 px.
🔍

Convolutions share detectors

A collar edge detector fires wherever the collar appears — not tied to a fixed pixel coordinate.

🏗

Stacked layers compose features

Edges → textures → collar shape → "shirt" semantic concept. Impossible with a single fixed transform.

📐

Pooling provides translation tolerance

Small position shifts don't corrupt the feature vector — fixes the pixel flattening problem.

🧠

End-to-end learning

The network discovers which local patterns are most diagnostic — button rows, collar shapes, plackets.

Phase 2 Architecture Plan
Conv2D(32, 3×3) → ReLU → MaxPool
Conv2D(64, 3×3) → ReLU → MaxPool
Conv2D(128, 3×3) → ReLU
GlobalAvgPool
Dense(256) → Dropout(0.5)
