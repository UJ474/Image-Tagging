# Image-Tagging

Project 11 Automatic Clothing Category Recognition

Inventory image tagging with handcrafted features and a small CNN

The current phase covers traditional machine learning on Fashion-MNIST: flattened pixels and HOG features with Logistic Regression, KNN, Random Forest and Linear SVM. CNN work follows in the later DL phase.

## Team work guides

Start with the [team index and six individual guides](docs/team/README.md). Each member has a shareable Word document and a matching Markdown guide with setup, owned tasks, verification, GitHub contribution steps and handoffs.

The guides specify the team's future implementation. Dataset loading, feature extraction, training, evaluation and the final classifier notebook will be contributed by the assigned members.
